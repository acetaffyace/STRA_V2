# Unified Version Review UX Report

## Primary flow

1. Select a game.
2. Let the system resolve the current event and previous comparable major event.
3. Choose an analysis mode.
4. For Version-vs-Version, select event A and event B.
5. Review the generated lifecycle-matched plan.
6. Start the review and follow it in the global queue.
7. Reopen the exact completed run from queue or recent history.

## Modes

The page now exposes automatic recommendation, recent impact, version comparison, longitudinal performance, and public opinion/event analysis. Version comparison immediately presents two event selectors and defaults B to the previous comparable event.

## Recovery UX

Recent Version Reviews are the normal reopening path. Run ID paste remains under `高级 / Debug` and does not create a new run. Missing events and incomplete historical acquisition have explicit Chinese states rather than an English saved-analysis error.

## Queue UX

The shared bottom-right queue shows general analysis and Version Review together, with persisted phases and an exact-result link.
