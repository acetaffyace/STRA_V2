## 本次修复的抓取问题

原逻辑使用了非官方的 `recent_created` 参数，并且看到某一页里有一条早于起始日的评论就停止，因此只抓到 100 条原始评论，窗口内错误地只留下 23 条。Steam 官方支持的参数是 `filter=recent`，其含义是按创建时间排序。

现在改为：使用官方 `filter=recent`，通过 cursor 翻页；只有当整页最晚评论都已经早于窗口起点时，才允许停止。修复后抓取 12,600 条原始评论，窗口样本从 23 条增加到 12,435 条。

2. **反作弊与优化**：评论提到外挂、反作弊不足、性能或优化问题。
3. **资源与战斗节奏**：8 月 5 日版本后评论中出现物资减少、落地缺少武器、战斗回报不足和武器调整等具体抱怨。
4. **社区氛围**：出现辱骂、压力队友、玩家行为恶化等表达。
5. **角色/皮肤与内容审美**：多条中文评论针对角色皮肤和设计表达负面意见。
