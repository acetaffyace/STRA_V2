# SentiNext 作品集 Demo 脚本（3 分钟）

1. **选择游戏（15 秒）**：打开 NINJA GAIDEN 4，指出这是 1000-review offline end-to-end product/system validation；展示离线来源和 Run 信息，不把 Fixture 说成模型质量 benchmark。
2. **五问首页（35 秒）**：展示 What changed / Why / Who / What matters / What should we do。没有比较基线时，明确显示 unavailable，不暗示“最近变化”。
3. **Evidence（35 秒）**：打开“缺陷与错误”，展示匹配数量、分页和已验证原话；说明每个引用都回到 canonical review。
4. **Action（30 秒）**：展示 FIX / IMPROVE / BUILD / AMPLIFY，以及 rationale、uncertainty、validation plan。
5. **Chat（35 秒）**：问：**“当前评论中玩家最常提到哪些问题？请给我原始证据。”** 展示 deterministic evidence-first 回答、verified citations 和 0 tool calls。
6. **Reports（20 秒）**：展示当前分析摘要，再说明月度 PDF 是另一个有明确窗口的报告，不与当前快照混淆。
7. **收尾（10 秒）**：固定说：**“SentiNext 的目标不是替代产品判断，而是把分散的玩家声音压缩成可追溯的决策信号，并让每个结论都能回到原始证据。”**
